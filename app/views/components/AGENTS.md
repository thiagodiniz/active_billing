# Component Library — Agent Reference

All components are plain HTML snippets from the Tailwind UI repository.
**When the user names a component, refer to it by its filename** (e.g. `03-simple-dark.html`).
Every path below is relative to `app/views/components/`.

## Usage conventions

- **Reference a component by filename** when asking to build or redesign a page. Example: "use `03-simple-in-card.html` for the invoices table".
- Components are standalone HTML fragments (no Ruby/ERB). Copy the relevant markup into an ERB partial and adapt dynamic content with `<%= %>` tags.
- All components assume Tailwind CSS is loaded in the layout. The project layout is `app/views/layouts/active_billing/application.html.erb`.
- Monetary fields follow the project convention: always stored in cents, rendered via the `active_billing_money` type helper.
